# あべむつき インスタお手本キット

**最終更新日**: 2026-07-11

これは、AI活用ジャンルの発信者・**あべむつきさんの設定で「プロのリール台本のお手本」を生成する**キットです。**セットアップ不要・ネタ案を渡すだけ**で動きます。

## 使い方

「**/my-abeinsta**」と打って、作ってほしいネタ案を伝えるだけ。

> 例: 「ClaudeとCanvaの連携ネタでお願いします」「楽天ROOMの始め方で1本見せて」

AIが「型をどう選び、どの事実を使い、どう組み立てたか」の設計3行つきで、あべさん流の台本を1本作って見せます。

## ⚠️ 一番大事な注意

**このキットが作る台本は「お手本」です。そのまま自分の投稿に使わないでください。**

- 台本の中の数字・実績・体験談は**全部あべむつきさんのもの**。自分のものとして発信すると実績詐称・丸パクリになります
- 参考にしていいのは、**型・構成・作り方の流れ**だけ
- 自分の台本は、スキル作成スキル（**/my-skill-create**）で自分用の台本スキルを作って、自分の設定・実体験から作りましょう

## このキットの位置づけ

1. まず /my-abeinsta で「プロならこう作る」を体感する（←今ここ）
2. その感覚を持って、/my-skill-create で自分用の台本スキルを作る（自分の過去の台本やお手本を読ませる）
3. 自分のスキルを使いながら育てて、自分の台本の精度を上げていく
