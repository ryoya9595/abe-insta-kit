# 技・方法紹介型

**最終更新日**: 2026-07-07

**この型は何か**: 1つの技・方法・テクニックを紹介する型（ジャンルを問わない。例: 裏ワザ・時短の方法・便利な使い方。AIジャンルならプロンプト）。技の中身を1つ全文・全手順で見せる単発サブタイプと、小さな要素（記号・言い回し・道具など）を番号付きで複数紹介する並列サブタイプの2つがある。複数を順位づけして比較したいならランキング型を使う。

**成立条件（この型を書くのに必要な事実の在庫）**: knowledgeまたは自分の素材に、実際に使える技・方法が少なくとも1つ実在すること。並列サブタイプで書くなら、番号付きで紹介できる項目が複数あること。

## 組み立ての要点

### 単発サブタイプ
- 冒頭は2パターンある。使い方の問題を指摘して「自分は大丈夫か」と不安にさせる問題指摘型と、テクニックの効果を直接提示して「何それ」で引く発見・好奇心型。迷ったら問題指摘型を選ぶ。自分に関係ある問題の方が視聴継続が強くなりやすい
- 冒頭で作った興味は、本編に入る前に具体的な失敗の言語化や対象の性質の説明で「見る理由」に変えてから、「こうやってみて」で本編へ接続する
- 本編は技の中身をそのまま見せる（全文・全手順）。説明だけで終わらせず、視聴者がそのまま真似できる形にする方が保存価値が高い
- 技には、テーマを差し替えて繰り返し使える型と、そのまま一度きりで使う型がある。繰り返し使える方が保存価値は高くなりやすい
- 本編を強める打ち手を、テーマに合えば使う。基本形のあとに強化版を重ねる2段見せ、実際の結果を見せて凄さを証明する、使う前後の対比や断言で効果を伝える、の3つ
- CTAは技のまとめ・全文が欲しい人に、いいねとコメントを促す形にする

### 並列サブタイプ
- 並列サブタイプのお題は、記号・言い回し・小物など、番号で並べられる小さな要素なら何でも使える
- 冒頭で紹介する項目と件数を言い切る（「よく見るこの4つの記号」等）。具体性と有益性に加えて、知らないと損する危機感を足すと強くなる
- 冒頭のあとに「知っているかどうかで差がつく」と伝えて本編へつなぐ
- 本編は項目を番号付きで紹介する。優劣をつけないのがランキング型との違い
- 各項目は「何の記号・コマンドか→どう使うか→効果」の流れで短く言い切る。最初の項目を最重要なものにすると入りやすい
- CTAは紹介しきれなかった分を一覧としてまとめ、配布物に誘導する
