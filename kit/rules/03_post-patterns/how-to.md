# ハウツー型

**最終更新日**: 2026-07-07

**この型は何か**: 作業・制作・活用の手順を紹介する型（ジャンルを問わない。例: 道具の使い方・何かの作り方・始め方）。単に手順を並べるのではなく、冒頭で有益性・意外性・具体性を出して「これ自分もやりたい」と思わせ、ハードル下げ→手順→CTAで「できそう」「試したい」まで感情を動かす。

**成立条件（この型を書くのに必要な事実の在庫）**: 自分の素材やknowledgeに、視聴者が同じ手順で再現できる実際のやり方（操作・制作・登録の流れ）が実在すること。

## 組み立ての要点

### 基本形
- 冒頭→ハードル下げ→本編→CTAの順で組み立てる。冒頭・本編・CTAは毎回入れ、ハードル下げは条件次第で省く
- 冒頭は「何ができる・稼げるか」という有益性を必ず入れる。入り方はテーマで選ぶ。流行りものから入る、意外な組み合わせから入る、実績から入る、警告・損失回避から入る（すでにやっている行動の間違いを指摘）、完成した成果物を先に見せる、実際の収益画面を見せる、など複数の形がある
- ハードル下げは、視聴者が実際に手を動かす作業がある台本では入れる（「初心者でも」「〇分で」等の一文）。設定変更や列挙が主役の台本では飛ばしてテンポを出す。テーマが難しいほど属性・工程・安心材料を厚めに重ねる
- 本編はSTEP・工程で、使う道具・サービスと作業内容を順番に説明する。工程数は3〜5が目安。実際の作業がそれより多くても、関連する操作をまとめて少ない塊に見せると簡単に感じる
- 本編の最後に「完成したらどうなるか」を入れて、本編からCTAへの橋渡しにする
- CTAは具体的な配布物（手順書・チェックリスト・テンプレ・解説動画など）に誘導する。本編が技術的なテーマほど配布物の価値が上がる。配布物が強いときは本編の途中で先出し予告を入れると最後まで見る理由になる

### ロードマップ型
- ゼロから立ち上げる全体の道筋を、登録からマネタイズまで順番に見せる。「何から始めればいいか分からない」層に直撃する
- 冒頭は実績を出してから「今ゼロから始めるならこの順番で」と宣言して掴む。実績者が言うこと自体が見る理由になる
- 本編は登録→方向性決め→情報収集→制作のように段階を順番に並べ、差し込める段に使う道具・サービスを添える。登録や方向性決めなど差し込めない段には無理に入れない
- 各段に「ここをミスるとどうなるか」の注意を添えると、保存価値と再現性の実感が上がる
- CTAは希少性訴求やコメント誘導で、手順一式の配布に接続する
- 実績・数字は自分が確認できる実数だけを使う

### 設定ミス警告型
- 「あなたが損してるのは設定のせい」と、視聴者のあるある悩みを言い当てて自分ごと化させる。すでに使っている道具・サービスが対象なので当事者意識が強い
- ハードル下げは挟まず、冒頭からすぐ本編（設定の直し方）に入ってテンポを出す
- 本編は設定を「どこを操作して何をオンにするか」の画面操作レベルで見せる。各設定に「やらないとどうなるか」を添える
- CTAは「ここまでは前提で、本当に大事なのはさらに一段深い話」と接続し、より深い配布物に誘導する
- 対象はインスタの設定でも、自分のジャンルの道具・アプリの設定でも成立する
