# 本音・持論型

**最終更新日**: 2026-07-07

**この型は何か**: 再現手順や比較で教えるのではなく、断言・持論・本音・スタンスで視聴者を動かす・共感させる型。発信者の人柄そのもので惹きつけ、ファン化や濃いフォロワー獲得に効く。見終わって「真似できる手順」が残るならハウツー型、「持論・スタンスへの共感」が残るならこの型と判定する。

**成立条件（この型を書くのに必要な事実の在庫）**: profileに、誇張や捏造なしに語れる実際の経験・信念・スタンスがあること。実績や経験は実在するものだけを使う。

## 組み立ての要点

情報配布型と違い、理由/共感ブロックや配布CTAが独立しないことが多い。本編（語り）→思想・持論→着地（呼びかけ・フォロー）で締めるのが基本形。

### 本音語り/自己開示
- 冒頭は衝撃的な状況・告白・問いで掴む。情報ではなく状況そのもので引く
- 本編は自分の経験・どん底・混乱状態を正直に語る。きれいにまとめず、弱みや苦境も隠さない
- そこから信念・教訓を1点で述べる
- 着地は「あなたもこう在ろう」という呼びかけやフォロー誘導にする。商品や継続の話は前面に出さない
- どん底→決断→這い上がり→教訓という物語構造にすると、「自分も変われるかも」という希望を与えやすい
- 弱みをどこまで見せるか決めて出す。見せるほど共感は強くなるが、実在する経験の範囲にとどめる

### 逆張り主張/議論喚起
- 冒頭で通説・常識を断言で否定する。「え?」を作る
- 本編でなぜその通説が間違っているかを持論で展開する。みんな対自分の対立構造を作る
- 自分の軸・思想を断言で締める。賛否が割れてコメントが動くことを狙う
- 着地は「これに共感する人が自分の客」と割り切る
- 嫌われ覚悟や前言撤回を前置きにすると、本音感が増して信頼されやすい
- 反論されそうな主張ほど、根拠を一つ持って断言で締める
