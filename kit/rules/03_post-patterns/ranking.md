# ランキング型

**最終更新日**: 2026-07-07

**この型は何か**: 複数の選択肢を順位づけして紹介する型。最後まで見ないと1位が分からない構成にすると、視聴維持を作りやすい。何を順位づけするかで組み立てが変わるため、対象ごとに組み立てが変わる（下の3タイプは例。技・道具・稼ぎ方など、自分のジャンルの対象に読み替える）。

**成立条件（この型を書くのに必要な事実の在庫）**: knowledgeに順位づけできる候補が3つ以上あり、それぞれの効果・特徴を一言で言えること。対話形式で書くなら、候補を出し合える相手がいること。

## 組み立ての要点

### 技・テクニックのランキング（例: 勉強法のコツ、AIならプロンプト）
- タイトルコールで対象と件数を明示する（「〇〇TOP5」等）。具体性と有益性が同時に伝わる形にする
- 冒頭でありがちな失敗や不満を一言で言語化してから本編に入ると、続きを見る理由になる
- 順位は下位から1位へ番号順に出す。優劣が最後まで分からない構成にして視聴維持を作る
- 各順位は「候補→なぜ効くか→どうなるか」の3拍子で短くまとめる
- 1位に入る直前に短い宣言文を挟んで間を作ると、期待が高まってから種明かしできる
- 冒頭の掴み方は不満の言語化のほかにも変化をつけられる。希少性（「知っている人だけが得している」）や、対象を複数列挙して母数を広げる見せ方もある

### 道具のランキング（例: 調理器具、コスメ、AIツール）
- 読み上げ役と評価役に分かれた対話形式で進める。タイトルコールはしない
- 番号順には出さず、まず誰もが知っている定番の候補に意外な順位をつけて掴み、最後に1位を出す
- 各順位は「何ができるか→使いどころ→強い言い切りの言葉（実績があれば添える）」の順で述べる
- 「もう時代遅れ」「使わないと損するレベル」のような強い言葉を要所に入れて離脱を防ぐ
- 中間の順位はランダムな順で出すと先が読めず飽きさせない

### 方法・やり方のランキング（例: 節約法、収益化の方法）
- 読み上げ役と評価役の対話形式で進める
- 冒頭は候補を「圏外」として否定するか、強い候補をいきなり出して掴む
- 番号順には出さず、各順位で「どんな内容か→実績→手軽さ→収益化できる規模感」の順で述べる
- 1位以外は簡単な始め方を添えてもよい
- 1位は手順を省き、実績と「今がチャンス」であることを強調して締める
