# 対話型

**最終更新日**: 2026-07-07

**この型は何か**: 2人以上の会話で見せる型。掛け合いで、相手の実績・体験・本音・一次情報を引き出す。会話そのものが中身になる。視聴者の疑問に答える内容も、新しいもの・話題の検証も、会話で見せるならここに含む。

**成立条件（この型を書くのに必要な事実の在庫）**: 自分の素材として、実在する相手（受講者・実績者・同業者など）との実際の会話が存在すること。架空の相手やセリフを作って書くことはできない。

## 組み立ての要点

サブタイプは目的で選ぶ。成果を出した相手に実績と方法を語ってもらうなら実績者インタビュー、1つのテーマを2人で深掘りするなら対談・1テーマ深掘り、視聴者と同じ悩みを相手に代弁させてその場で答えるなら生徒の悩みインタビューを選ぶ。

### 実績者インタビュー
- 誰が・何で・どれくらいの期間で成果を出したかを冒頭で提示する（手段＋期間＋成果の大きさ）。視聴者と近い属性の相手だと「自分にもできそう」が強くなる
- 質問は、始めた時期→期間→成果（証拠になる画面があれば見せる）→やり方→その手段固有の強み（SNS不要・スキル不要等）→今後の目標、の順で短く畳みかける
- 数字・再現性が出る質問と、証拠になるものを見せる質問を必ず入れる
- 最後に本人の言葉で一言アドバイスをもらって締める。証言だからこそ刺さる
- CTAはその人が成果を出した方法を配布物にして、名前をコメントで誘導する。本編の実績とCTAの配布物を一致させる
- この型は冒頭が強くないためリーチは伸びにくいが、最後まで見る人が濾過されて本気度の高い見込み客が集まりやすい

### 対談・1テーマ深掘り
- 1つのテーマ（疑問・お題・検証したいもの）を会話で投げるところから始める。「これで終止符を打つ」のような強い宣言を添えてもよい
- 本編はよくある通説・疑問を出して掛け合いで深掘りするか、実際にやってみた結果を見せながら評価する。聞き手が「どういう理由?」「本当に?」と視聴者の代わりに掘ることで、知りたい順に話が進む
- 相手の経験・本音・数値を引き出す。良い点だけでなく気になる点も忖度なく出すと信頼が上がる
- オチは「とはいえ」「結論」で本音・等身大の結論を1点に絞って返す。きれいにまとめすぎないほうがリアル感が出る
- CTAは軽めでよい。資料誘導や次回予告でもよい
- 権威のある相手とのコラボの場合は、冒頭で相手の実績を一言添える

### 生徒の悩みインタビュー
- 冒頭で聞き手が視聴者と同じ悩みを代弁する
- 本編は答え役が結論・コツを出し、聞き手が相槌や追加質問で視聴者の疑問を代弁しながら、具体的なやり方まで落とし込む
- よくある間違い・NG行動を名指しで否定してから理由を腹落ちさせ、正しい第一歩を示すと刺さりやすい
- 自分の体験を根拠に使う場合は、実際に確認できる範囲だけにする
- CTAは配布物やフォローへの誘導
