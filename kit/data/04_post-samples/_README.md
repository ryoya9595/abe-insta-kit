# data/04_post-samples/（参考投稿のストック＝あなたの見本棚）

> 名前の由来: 「この台本**ストック**して」の合図で貯まる場所だから post-samples。

**最終更新日**: 2026-07-07

競合の伸びてるリール台本と、あなた自身の伸びた投稿（勝ちパターン）を貯める場所。台本の「形」（構成・尺・テンポ）はここから借りる。**保存はAIがやる**（「この台本ストックして」と貼るだけ）。

## 保存のルール

- 1投稿 = 1ファイル。ファイル名は `テーマ_日付.md`（例: `kotei-hi_20260707.md`）
- 各ファイルの先頭に: 型（patternsの型名）／出典（アカウント名 or 自分）／数値（分かる範囲）／保存日／伸びてる理由メモ1行
- 自分の伸びた投稿は「【自分の勝ちパターン】」と明記（勝ちパターンだけは言い回しごと再利用できる。競合のものは型・構成だけ借りる）
- 同じ型のストックが3本を超えたら、AIが入替・整理を提案する
- **ここに保存した他人の台本は分析・型の参考専用**。文章をそのまま・ほぼそのまま投稿するのは著作権侵害になり得るのでNG

## 見本

> 先頭に `_` が付くファイルは出荷時の見本（不要になったら消してよい）。あなたのストックには `_` を付けない。

- `_sample-claude-canva.md` … この書式の実例（出荷時サンプル。自分のストックが溜まったら消してよい）
