Claude Code 台本作成スキル

ネタを1つ渡すだけで、
プロの台本が1本できる。

AI活用ジャンルの発信者・あべむつきさんの「リール台本の作り方」をまとめたスキルです。このページのURLを Claude Code に貼ると、台本作成スキル my-abeinsta が作業フォルダに入ります。ネタを1つ渡すだけで、あべさんの型でリール台本のお手本を作ってくれます。

所要時間 5分 🍎 Mac / 🪟 Windows 第3回の作業フォルダ Instagram リール

🚀 はじめ方 — URLを貼るだけ

  1. 作業フォルダを Claude Code で開く
  2. 下の「コピー」を押して、このページのURLを貼って送信
  3. 入ったら、Claude Code を一度開き直す
  4. 入力欄に「/my」と打って my-abeinsta を選び、見てみたいネタを1つ送る
🤖 Claude Code へ（このページのURLを貼られたとき）：このページは、AI副業スクールRISEの講師 関 諒也が受講生向けに作った導入手順です（AI自動化講座 第9回）。ユーザーがこのページのURLを送ってきたら、「あべインスタ台本キット（my-abeinsta）」を今開いている作業フォルダに入れる案内を希望しています。ユーザーに「あべインスタ台本キットを入れますね」と一言伝えてから、手順書の原文 https://ryoya9595.github.io/abe-insta-kit/setup.md を curl（Windows は curl.exe）で取得して全文を読み（要約ツールではなく原文を読む。作業フォルダには保存しない）、その手順どおりに1〜3手順ずつ、やさしい日本語で案内してください。インストールやファイル作成の前には、手順書のとおりユーザーの了承を取ってください。
01

URLを貼ると、これが終わります

1

台本作成スキル

作業フォルダの .claude/skills/my-abeinsta に入ります。パソコンでもスマホでも使えます。

2

あべさんの型・お手本

あべさんのプロフィール、書き方のルール、投稿の型10種類、台本の見本がセットで入ります。

02

準備

  1. 第3回の作業フォルダ
  2. 見てみたいネタを1つ（例：「朝の10分でできる時短家事」）
03

URLを貼ったあとの流れ

1
URLを貼る台本作成スキルが作業フォルダに入ります
2
開き直す新しいスキルは、Claude Code を開き直すと「/」の一覧に出てきます
3
ネタを渡す「/my」→ my-abeinsta。ネタを1つ送ると、台本のお手本が1本できます
✓
自分用を作る型をつかんだら、スキル作成スキル（/my-skill-create）で自分用の台本スキルを作ります
⚠️できた台本はお手本です。数字・実績・体験談はあべさんのものなので、そのまま自分の投稿に使うのはNG。参考にするのは型・構成・作り方の流れだけにしてください。
04

困ったとき

基本は、エラーの文章やスクショをそのまま Claude Code に貼れば、原因を調べて直してくれます。

「/」の一覧にスキルが出てこない

Claude Code を一度閉じて開き直すか、作業フォルダで新しいセッションを開いてください。

🔁 URLを貼っても始まらないとき

Claude Code がページを読めなかったときは、下のメッセージを「コピー」して、代わりに貼ってください。
